# 大角君工具箱 Anime Edition

二次元风格 Android 修机玩机助手。

## 项目介绍

大角君工具箱 Anime Edition 是一个开源 Android 项目，主要用于辅助学习和整理 ADB / Fastboot 修机流程。

手机端负责：

- 查看修机流程
- 查看玩机说明
- 复制常用 ADB / Fastboot 命令
- 记录刷机前注意事项
- 作为电脑端大角君工具箱的辅助说明

真正执行刷机操作，建议仍然在电脑端使用 ADB / Fastboot 工具。

## 功能

- 修机模式：卡开机、Recovery、Fastboot、9008 判断
- 玩机模式：TWRP、Magisk patched boot、vbmeta、A/B 槽位说明
- 命令库：常用 ADB / Fastboot 命令一键复制
- 资料说明：驱动、固件、数据、Bootloader 风险提示
- 二次元霓虹风格 UI
